# Briefing do Projeto

- Servico: sistema personalizado de prospeccao comercial em extensao Chromium.
- Objetivo: usar o Instagram de uma conta famosa como origem e encontrar, entre os seguidores visiveis, perfis com maior e menor potencial de compra para a Impacto Web.
- Usuario: time comercial da Impacto Web.
- Dados: usernames, nomes, bios, links e metricas publicas exibidas pelo Instagram.
- Persistencia: IndexedDB local, sem backend e sem sincronizacao externa.
- Restricoes: nao automatizar login, nao usar API privada, nao contornar bloqueios e nao enviar mensagens automaticamente.
