# Criterios de Aceite

- [x] A conta-semente nao e adicionada como lead.
- [x] Seguidores duplicados sao removidos da amostra.
- [x] A amostra e distribuida ao longo da lista coletada.
- [x] Cada seguidor analisado recebe score de 1 a 5.
- [x] A origem `@semente` fica vinculada ao seguidor.
- [x] A dashboard exibe maior e menor potencial separadamente.
- [x] Perfis privados continuam usando os sinais publicos disponiveis.
- [x] Login e bloqueios do Instagram geram mensagens claras.
- [x] A extensao nao envia DMs nem automatiza autenticacao.
- [ ] Coleta real de seguidores validada em sessao autenticada do Instagram.
